## 공통 응답·에러 계약

### 응답 구조

- 성공 응답은 별도 envelope 없이 **DTO 그대로** 온다.
- 에러만 `{ code, name, httpStatus, message }` 형태의 정규화된 `ApiError` 타입.
- 프론트 분기는 `code`로, 사용자 노출은 `message`를 그대로 쓸 수 있다.

### ⚠️ 성공 응답에는 공통 envelope가 없다

- **성공 시 컨트롤러 DTO가 그대로 최상위 JSON**으로 온다. `{ data, success, ... }` 래퍼 **없음.**
- 상태 코드 관례: 조회/로그인/재발급 `200`, 생성 `201`, 수정·삭제·상신 `204`(본문 없음).
- 페이징 응답만 표준 구조를 가진다(성공 래퍼가 아니라 Spring `Page` 구조).

**성공 예시 (로그인):**

```json
{ "accessToken": "eyJhbGciOiJIUzI1NiJ9..." }
```

### 에러 응답 (에러일 때만 통일된 구조)

```json
{
  "code": "ROLE_002",
  "name": "PERMISSION_DENIED_EXCEPTION",
  "httpStatus": 401,
  "message": "권한이 없습니다"
}
```

- 필드: `code`(도메인 에러코드), `name`(예외 enum 이름), `httpStatus`(int), `message`(한국어 사용자 메시지).
- **프론트 분기는** `code`**로 하고, 사용자 노출은** `message`**를 그대로 쓸 수 있다.**



### 프론트 분기에 중요한 대표 에러 코드


| code               | httpStatus | 의미 / 프론트 처리                                                                     |
| ------------------ | ---------- | ------------------------------------------------------------------------------- |
| `VALIDATION_ERROR` | 400        | Bean Validation 실패. `message`에 첫 위반 필드 메시지 → 폼 에러로 노출                           |
| `AUTH_001`         | 401        | 아이디/비밀번호 불일치(로그인 실패) → **재발급 대상 아님**, 로그인 폼 에러                                  |
| `ROLE_002`         | 401        | 권한 없음/토큰 무효. **재발급 실패의 신호** → 로그인 이동                                            |
| `ROLE_003`         | 403        | 부서 관리자가 타 부서 사원 수정 시도 → **재발급 금지**, 권한 부족 UX                                    |
| `COMMON_001~007`   | 400        | 공통 입력 검증 실패(필수값/공백/양수/형식/시간범위 등)                                                |
| `FILE_001~006`     | 400/404    | 파일 MIME/크기/확장자/파일명/미존재 (5번 참조)                                                  |
| `*_NOT_FOUND_*`    | 404        | 리소스 미존재(도메인별: `BOARD_003`, `DRAFT_004`, `EMP_001`, `CHAT_001` 등) → not-found UX |
| (핸들러 미처리)          | 500        | `code`가 예외 클래스명, `message`가 예외 메시지 → 일반 오류 토스트                                  |


> ⚠️ **인터셉터 재발급 조건을 좁혀라.** 재발급 대상은 `code === 'ROLE_002'`**(토큰 무효)** 로 한정한다. `AUTH_001`·`ROLE_003`은 재발급 경로에 넣지 않는다.
> 전체 에러코드 목록: `ApplicationErrorCode.java`(도메인), `AdapterErrorCode.java`(인증/파일 저장).
