# Claude 명령어: Update Roadmap

로드맵 표의 `완료 여부` 셀을 체크하고 진행률·마일스톤 상태·최종 업데이트 날짜를 갱신합니다.

## 대상 로드맵 구조 (전제)

- 태스크는 **마크다운 표** 안에 존재. 마지막 컬럼 = `완료 여부` (`☐` 미완료 / `☑` 완료).
- 태스크 ID = `TX.Y` (T0.1, T1.2, T2.3 ...), 행 시작은 `| **TX.Y** |`.
- 마일스톤 헤더 = `### M0 — 제목 · 근거: ...` 형식.
- 표에 `Depends-on` 컬럼 존재 → 의존성 검증에 사용.

## 대화형 프로세스

1. 로드맵 파일 읽기
2. 미완료 태스크 목록 표시 (`완료 여부`가 `☑`가 아닌 행만)
3. "어떤 Task를 완료했나요? (예: T0.1 또는 T1.2,T1.3)" 질문
4. 사용자 입력 받기
5. 각 태스크 행의 `완료 여부` 셀 → `☑`
6. 마일스톤 완료 여부 자동 확인 및 헤더 갱신
7. 진행률 통계 + 최종 업데이트 날짜 갱신
8. 변경 요약 출력



## 업데이트 규칙



### 태스크 완료 체크 (표 셀)

- 대상: `| **TX.Y** |` 로 시작하는 행
- 마지막 셀(`완료 여부`)이 `☐` 또는 빈 값 → `☑` 로 교체
- **Task 제목·설명·중요도·복잡도 셀은 절대 수정 금지** (완료 여부 컬럼만 변경)
- 이미 `☑`인 행은 skip



### 의존성 검증 (soft warning) — ⚠️ 이 로드맵 특성

- 완료 처리 전, 해당 행의 `Depends-on` 셀에 적힌 태스크들이 모두 `☑`인지 확인
- 하나라도 미완료면 **차단하지 않고 경고만** 출력:
`⚠️ T1.4는 Depends-on(T1.3)이 아직 미완료입니다. 그래도 완료 처리했습니다.`
- `Depends-on`이 `—`이면 검증 없이 통과



### 마일스톤 상태 (헤더)

- 마일스톤 표의 **모든 태스크가** `☑` → 헤더의 `· 근거` 바로 앞에  `✅` 삽입
  - Before: `### M0 — 아키텍처 배관 (Walking Skeleton) · 근거: PRD §A, §A-7`
  - After:  `### M0 — 아키텍처 배관 (Walking Skeleton) ✅ · 근거: PRD §A, §A-7`
- 이미 ✅가 있으면 skip



### 진행률 + 날짜 (개요 하단에 삽입/갱신)

- 위치: `## 🗺️ 개요` 라인 바로 다음 (없으면 삽입, 있으면 교체 — idempotent)
- 형식:

```
📅 최종 업데이트: <오늘>
📊 진행 상황: <완료>/<총> Tasks 완료 (<퍼센트>%) — M0 <상태> / M1 <상태> / M2 <상태> / M3 <상태>
```

- 마일스톤 상태 표기: 전부 완료 `✅` / 일부 완료 `진행 중(x/n)` / 0개 `대기`



## 구현 상세 (실행 로직)



### 카운트 산출 — ⚠️ 하드코딩 금지

- **총 Task** = 파일 전체에서 `| **T` 로 시작하는 행 개수 (동적)
- **완료 Task** = 그 중 마지막 셀이 `☑`인 행 개수
- 진행률 = round(완료 / 총 × 100)%
- ⚠️ **하단** `## ✅ 정합성 검증 체크리스트` **섹션의** `✅`**는 태스크 완료가 아님 → 카운트·수정 대상에서 제외**. 오직 `| **T...☑ |` 표 행만 집계·변경한다.



### 마일스톤 스코프 판정

- `### M0 —` ~ 다음 `### M` 헤더 직전까지가 한 마일스톤 블록
- 블록 내 `| **T` 행들의 `완료 여부`로 완료/진행중/대기 판정



### 날짜

- `Bash(date +%Y-%m-%d)`로 오늘 날짜 획득 → `**📅 최종 업데이트**` 갱신 (YYYY-MM-DD)



## 예시 (이 로드맵 기준)

**Before:**

```markdown
### M0 — 아키텍처 배관 (Walking Skeleton) · 근거: PRD §A, §A-7
...
| **T0.1** | ... | §A-1 | — | ... | | | ☐ |
```

**After (M0 전체 완료 시):**

```markdown
### M0 — 아키텍처 배관 (Walking Skeleton) ✅ · 근거: PRD §A, §A-7
...
| **T0.1** | ... | §A-1 | — | ... | | | ☑ |
```

**개요 하단:**

```markdown
## 🗺️ 개요
**📅 최종 업데이트**: 2026-07-06
**📊 진행 상황**: 8/17 Tasks 완료 (47%) — M0 ✅ / M1 진행 중(1/6) / M2 대기 / M3 대기
```



## 주의사항

- 태스크 ID는 `TX.Y` 형식 (T0.1, T1.5 ...)
- `완료 여부` 컬럼만 변경, 나머지 셀 불변
- 총 Task 수는 **항상 파일에서 재계산** (17 같은 고정값 사용 금지)
- 여러 태스크 동시 완료 지원 (예: T0.1,T0.3,T0.6)
- `Depends-on` 미충족 시 차단 없이 경고만
- 하단 정합성 체크리스트의 ✅는 건드리지 않음



## 출력 예시

```
현재 미완료 Task:

✅ T0.1 완료
✅ T0.3 완료
✅ T0.6 완료

📅 최종 업데이트: 2026-07-06
```
