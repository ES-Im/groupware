🛠️ 관리자 운영 화면 · UI/UX 정착
07-12 하루에만 13건이 커밋되며 홈 대시보드 도메인이 신규 추가됐고, 조직도·부서 근태 화면이 탐색형/마스터-디테일 레이아웃으로 재구성됐다. 신규 업무 도메인 착수분은 없고, 최근 흐름은 관리자 운영 화면 보강 + 기존 화면 완성도 향상에 집중돼 있다.
  • 진행 중: 신규 사원 가입승인 · 조직소속 배정 — 화면 + 배정 API 노출·보안설정 정리 커밋 완료
  • 진행 중: 홈 대시보드 위젯 — 출근·미결재·안읽은 쪽지·내 일정 4종, 데이터 정합 보강 여지
  • 진행 중: 레이아웃 재구성 확산 — 조직도(트리+상세)·부서 근태(마스터-디테일) 적용, 잔여 화면 확산
  • 지속: 부서 활성화 버그 등 버그 수정 및 테스트 보강
이 대시보드는 로컬 저장소 상태(git · ROADMAP · 도메인 모델)를 반영한 스냅샷입니다. 자동 갱신은 예약 작업으로 매일 재생성됩니다.
